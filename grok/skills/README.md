# Grok-specific skill variants

A file here named `<skill>.md` (for example `dnd-narration.md`) replaces
`claude_skills/<skill>/SKILL.md` in the Grok kit. Leave this folder empty unless
Grok genuinely needs different wording: every variant is a second copy that can
drift from the shared skill. There are none today; the shared skills already
cover clients without roll cards (the roll block above the scene).
